:::caution[Requires documentation]
The Vinnie repository doesn't include a license file yet. Until a license is published, default copyright
applies: the code is viewable on GitHub, but no permission to use, modify, or redistribute it is granted.
:::

When a license is chosen, it will be added to the repository as `LICENSE` and summarized here.

## Third-party software

Vinnie is built on open-source projects with their own licenses, including Tauri, React, Monaco Editor, the
Model Context Protocol TypeScript SDK, and many Rust crates and npm packages. Their licenses are in the
respective packages. Ollama and MCP servers you install are separate software under their own licenses.

These docs are built with [Astro](https://astro.build) and [Starlight](https://starlight.astro.build).
