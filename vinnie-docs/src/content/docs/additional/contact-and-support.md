## Get help

1. **Search these docs** with <kbd>Ctrl</kbd> <kbd>K</kbd>, especially [Troubleshooting](/troubleshooting/common-error-messages/).
2. **GitHub issues**: report bugs and ask questions at
   [github.com/1anP33in/vinnie/issues](https://github.com/1anP33in/vinnie/issues).

## When reporting a bug

Include:

- **Settings → About & diagnostics → Copy diagnostics** (Vinnie and Tauri versions, OS, Ollama status, folders);
- the model you used;
- steps to reproduce, and what you expected;
- relevant lines from `%LOCALAPPDATA%\ai.vinnie.desktop\logs\vinnie.log`. Logs don't contain message or file
  contents, but check for anything private before posting;
- for agent problems, the task report, and the debug view if enabled.

## Security issues

Don't post them publicly. See [Reporting vulnerabilities](/security/reporting-vulnerabilities/).
