If you find a security issue, for example a way for the model to escape the project folder, bypass the command
policy, or read MCP secrets, please report it **privately** first.

## How to report

- If GitHub's **private vulnerability reporting** is enabled for the repository, use **Security → Report a
  vulnerability** on [github.com/1anP33in/vinnie](https://github.com/1anP33in/vinnie/security).
- Otherwise, open a GitHub issue that **only** asks the maintainer for a private contact, without details of the
  problem.

Please include the Vinnie version (**Settings → About & diagnostics → Copy diagnostics**), the steps to
reproduce, and the impact.

:::note[Requires documentation]
The project doesn't have a published security policy (`SECURITY.md`) with response times or a dedicated contact
yet. This page will be updated when one exists.
:::
