Vinnie installs these skills into `%APPDATA%\ai.vinnie.desktop\skills\` on first start:

| Skill | Selected when, for example |
| --- | --- |
| FiveM Development | *fivem*, *fxmanifest*, *esx*, *qbcore*, *nui*; Lua or FiveM projects. Includes the reference `fxmanifest.md` |
| Lua Development | *lua*; projects using Lua |
| Web Development | *react*, *dashboard*, *frontend*, *api*, *endpoint*; JavaScript/TypeScript or Node.js projects |
| TypeScript Development | *typescript*, *tsconfig*; TypeScript projects |
| Python Development | *python*, *pytest*, *django*, *fastapi*; Python projects |
| C# Development | *c#*, *dotnet*, *asp.net*, *unity*; .NET projects |
| Git Assistance | *git*, *commit*, *branch*, *github*, *repository*; hints the `github.*` MCP tools |
| Debugging | *bug*, *error*, *crash*, *exception*, *failing* |
| Database Assistance | *database*, *sql*, *mysql*, *postgres*, *oxmysql*; hints database MCP tools |
| Documentation | *readme*, *docs*, *changelog*, *guide* |

Each built-in skill is installed **once**. Your edits are never overwritten, and a built-in skill you delete
isn't reinstalled. Disable one instead if you might want it back.
