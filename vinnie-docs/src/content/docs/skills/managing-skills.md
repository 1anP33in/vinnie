---
title: "Managing Skills"
description: "Enable, disable, edit, delete, and activate skills."
sidebar:
  order: 7
---
The **Skills** screen lists installed skills with an on/off switch.

- **Switch off** a skill to stop it from ever being selected.
- **Click** a skill to edit it, manage reference files, export it, or delete it (built-in skills aren't
  reinstalled after deletion).
- **Use in this session**: *Auto* (Vinnie decides), *On* (always used), or *Off* (never used), until Vinnie
  restarts. The same choice is available from the book button next to the message box.

Skill activity (*Using …*, *Loaded …*, failures) appears in the **Activity** feed, and each task's timeline
starts with *Using skills: …* when skills were chosen.
