The ice dragon is Vinnie's mascot and status companion.

**Today**, the dragon appears as the **status indicator** at the left of the status bar: the dragon mark followed
by *Vinnie: Idle* or what Vinnie is doing. It's driven only by real activity: no simulated animations.

:::caution[Planned]
An **animated 3D ice dragon viewer** that reacts to Vinnie's activity is planned for a future phase (Phase 5).
The welcome screen shows a placeholder labeled *"Ice dragon viewer — Planned for a future phase"*. See the
[Roadmap](/additional/roadmap/).
:::

The viewer will use the same [dragon states](/dragon/dragon-states/) the indicator uses today.
